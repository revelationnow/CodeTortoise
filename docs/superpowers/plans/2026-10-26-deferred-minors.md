# Review UI redesign — deferred minors Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the minor findings deferred during the review UI redesign (merged in ab2f2e7) and apply the owner's four decisions of 2026-10-26.

**Architecture:** Small, independent fixes grouped by area into eleven tasks. Each item says what is wrong, the fix, and the test that pins it. Behaviour changes get a test that fails first; tests added for behaviour that already works are mutation-checked (break the code, watch the test fail, restore). Refactors keep behaviour; the existing tests are their net.

**Tech Stack:** React 19, react-router 7, Vite, TypeScript strict, vitest (node env, `src/**/*.test.ts`), Playwright against the built bundle; FastAPI + pydantic v2 backend, pytest, ruff.

**Spec:** `docs/superpowers/specs/2026-10-25-review-ui-redesign-design.md` stays the binding authority, amended by the owner's decisions below. Each item's original finding is restated in its task; no other source is needed.

## Review Focus

1. **Shortcuts switched off**: J, K and F do nothing on the Flows tab and in the stepper; Enter and Space stay the focused control's own; switching back on restores them; the choice survives a reload; with storage blocked the shortcuts are on and nothing throws. Tests in Task 10.
2. **A phone with 30+ flows**: rows at least 44px apart, every tick reachable by a finger without hitting its neighbour's box, nothing scrolls sideways on the real scroller. Tests in Task 9 (row pitch) and Task 11 (`sideways`).
3. **A reading stored before `related`**: no tick box, every chip still shown, contract causes in the first function group among their flows or on the end line, nothing throws. Tests in Task 8 (unit) and the existing `flow-groups.spec.ts` Review Focus 1 test.
4. **Reopen failing part-way**: the server refuses or errors — no mark changes, the error shows, and the row's marks are as they were. Tests in Task 9.
5. **The AI usage panel opened from the pill or from ⋯**: focus moves into it; Escape or Close returns focus to whichever opened it; J, K and F do nothing while it has focus. Tests in Task 3.
